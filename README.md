# My voxel engine

## Introduction

This repository holds the code for my first voxel engine, built from scratch using C++ and OpenGL.

## Getting started on MacOS

```bash
brew install cmake glfw
```

## Getting started on Linux

Debian / Ubuntu:

```bash
sudo apt install build-essential cmake libglfw3-dev libgl1-mesa-dev
```

Fedora:

```bash
sudo dnf install gcc gcc-c++ cmake glfw-devel mesa-libGL-devel
```

Arch:

```bash
sudo pacman -S base-devel cmake glfw mesa
```
